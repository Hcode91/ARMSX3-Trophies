# Custom trophy packs

Packs made with ARMSX3-Trophies. Install one from the app: Trophies > Import custom trophy pack.

| Pack | Game | Notes |
| --- | --- | --- |
| `arkedo-custom-trophies.zip` | Arkedo Series (NPUB30703, NPWR03105_00) | 24 trophies and a platinum. `NPWR03105_00.yml` is its rules file, for reading. |

A pack only contains rules and icons made for it, never game files.
